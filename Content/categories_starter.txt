# Message Slots — starter category packs
#
# Format:
#   @id | Display Name | optional hint
#   word word word ...        (whitespace or newline separated, case-insensitive)
#
# THE CRITICAL PROPERTY IS SHORT WORDS.
#
# A turn offers 5 reels over 3 spins. The player will usually be choosing from
# a handful of letters, so a category whose words are all 7+ letters is
# unplayable no matter how well written it is. Every category below is weighted
# hard toward 3-5 letter words, and each one needs a healthy set of 3-letter
# entries or it will produce dead turns. When adding a category, count the
# 3- and 4-letter words first — if there are fewer than ~15, it isn't ready.
#
# Compiled by tools/compile_categories.py into
# Sources/GameCore/Resources/categories_starter.json
